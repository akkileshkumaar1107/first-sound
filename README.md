# FIRST SOUND – Listening to Life Before Birth

Basic image processing of real maternal and fetal ultrasound scans (Medical Imaging mini project,
SRM Institute of Science and Technology).

Run locally:

    pip install -r requirements.txt
    streamlit run app.py

Sample scans: HC18 (van den Heuvel et al., PLoS ONE 2018, CC BY 4.0) and FETAL_PLANES_DB
(Burgos-Artizzu et al., Sci. Rep. 2020). Hero video and banner art are AI-generated.
Teaching software, not a medical device.
